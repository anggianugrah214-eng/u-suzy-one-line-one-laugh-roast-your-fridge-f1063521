A single one-line roast of a fridge, written by a tiny Node program to
`/output/entry.txt`:

> You light up like you're thrilled to see me at 3AM, but the freshest thing inside you is your own light bulb.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

Node 22, standard library only. The program validates the line against the
competition gate (1–200 characters, one line) before writing it as UTF-8
with no trailing newline.
